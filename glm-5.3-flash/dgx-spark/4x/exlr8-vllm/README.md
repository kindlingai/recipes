# glm-5.3-flash-exlr8-gx10 (external)

GLM-5.3-Flash with exlr8 (EXL3-trellis) experts on GB10 with vLLM and mentat, TP=1/2/3/4. This recipe lives in its own repo, [kindlingai/glm-5.3-flash-exlr8-gx10](https://github.com/kindlingai/glm-5.3-flash-exlr8-gx10): the image, the
launchers, the gate and its issues are there.

This folder holds only its card data, so the recipe shows up in the [index](../../../../README.md#recipes) and on the
site. [kindling.json](kindling.json) is a copy of that repo's `kindling.json`; the Index workflow refreshes it daily
(`tools/sync_external.py`). Edit the numbers there, not here.

```bash
npx @kindlingai/recipe glm-5.3-flash-exlr8-gx10    # clones kindlingai/glm-5.3-flash-exlr8-gx10
```
